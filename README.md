# 公共ノート

公共の一問一答95問を、カード学習と記述テストで覚える小さなWebアプリ。

**公開先（Pages設定後）:** https://true-nosuke.github.io/koukyou-cards/

## 機能
- 8テーマ・95問。スマホ／PC、ライト／ダークモードに対応
- カードの表裏、逆向き学習、ランダム出題、テーマ・問題数の選択
- 「もう一度」は同じセッションの少し後に再出題
- 簡易間隔反復：正答で1・2・4・8・16・30日後、誤答で10分後。2連続正答を「定着」と表示
- 1問ずつ採点する記述練習と、20問を選べる7分の模擬テスト
- 記述は生の入力と模範解答を完全一致で比較。空白・記号・全半角・別表記は補正しない
- 検索、お気に入り、苦手の絞り込み、連続学習日数とセッション履歴
- 左右スワイプ判定、任意の2秒瞬発力チェックと瞬発力不足フィルター
- 試験日のカウントダウン、カードごとの自分用メモ（200文字）
- localStorage保存、検証付きJSONバックアップの読み書き、リセット確認
- キーボード：Spaceで解答、1でもう一度、2でわかった

## 起動
ビルド・外部パッケージ不要。静的ファイルを配信するだけです。

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```

`index.html`、`style.css`、`data.js`、`app.js`、`icon.svg`、`manifest.webmanifest` が実行ファイルです。全パスを相対参照しており、GitHub Pagesのプロジェクトパスでも動作します。

## GitHub Pages
Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/ (root)` → Save。
`.nojekyll` によりJekyll処理を省略します。更新はmainへのコミットで反映されます。

## データとプライバシー
提供された「2年公共 第2回確認テスト」のプリントに基づく95問です。長い問題文は一部要約・整文し、解答の表記は提供プリントを優先しています（例：40番「自由」）。原本と併せてご確認ください。元画像や学校・個人を特定する情報は含めていません。教材の利用・公開範囲に関する権利は利用者側でも確認してください。

ログイン、解析、広告、外部通信、クラウド同期はありません。学習状態はこの配信元のブラウザlocalStorageだけに保存されます。プライベートブラウズやブラウザデータの削除で失われる可能性があります。定期的にJSONを書き出してください。進行中のセッション自体はメモリ内にあり、ページ再読み込みで終了します。採点済みの回答は随時保存されますが、模擬テストは終了時まで保存されません。

Memoraxとは無関係の独立したアプリです。簡易間隔反復は独自の実装であり、特定アプリのアルゴリズムを再現するものではありません。Service Workerは搭載しておらず、オフライン起動は保証しません。

## 動作確認

アプリ本体にnpmパッケージは不要です。開発用のブラウザテストだけPlaywrightを使います。

```sh
npm install
npx playwright install chromium
# 別ターミナルで python3 -m http.server 8000 を起動
npm test
```

既存のChromiumを使う場合は `CHROMIUM_PATH=/path/to/chromium npm test`。公開先の確認には `BASE_URL=https://true-nosuke.github.io/koukyou-cards/ npm test` を使えます。95問の件数・重複、スワイプ、2秒判定、空白を含む完全一致、模擬テストの時間切れ、検索、メモ、保存、バックアップの読み書きと不正形式の拒否、リセットをテストします。テストでは独立した一時ブラウザを使い、利用者の学習データを変更しません。スクリーンショットは一時フォルダ（`TEST_OUTPUT` で変更可）に保存します。
